# Kalkulator Piano 🎹

Kalkulator saintifik interaktif dengan efek suara synthesizer piano. Aplikasi ini menggabungkan fungsi matematika dengan elemen musikal.

## Fitur Utama
- Kalkulasi operasi matematika standar dan saintifik.
- Efek suara tuts piano saat tombol ditekan.
- Antarmuka pengguna visual interaktif.

## Teknologi yang Digunakan
- Python
- Tkinter (Antarmuka Pengguna)
- Pygame (Manajemen Suara)

## Cara Menjalankan
1. Unduh atau clone repositori ini.
2. Pastikan pustaka \pygame\ telah terinstal. Jika belum, jalankan: \pip install -r requirements.txt3. Jalankan skrip utama melalui terminal: \python main.py
